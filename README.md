# shh 🤫

**화면에는 아무것도 안 보이게, 타이핑만으로 메모하는 맥 메뉴바 앱**

수업 중에 떠오른 아이디어를 적고 싶은데, 메모장을 켜는 것도 노트를 꺼내는 것도 눈치 보일 때가 있죠.
shh는 단축키 하나로 "몰래 입력 모드"를 켜면, 화면에는 아무 변화 없이 입력한 내용이 메모로 저장돼요.
옆에서 보면 그냥 키보드를 두드리는 것처럼 보일 뿐이에요.

## 주요 기능

- **⌃⌥;** 로 몰래 입력 모드 켜기. 어떤 앱을 보고 있든 동작해요.
- 타이핑한 내용은 화면 어디에도 표시되지 않아요. 한글 입력도 그대로 돼요.
- 같은 단축키나 **Esc**로 끄면, 그동안 입력한 내용이 메모 1개로 저장돼요.
- 메뉴바의 `shh`를 누르면 최근 메모 5개를 볼 수 있어요. 메모를 누르면 전체 내용 확인과 복사가 가능해요.
- Dock 아이콘이나 창 없이 메뉴바에서 조용히 동작해요.

## 사용법

| 동작 | 방법 |
|---|---|
| 몰래 입력 시작 | `⌃⌥;` (Control + Option + ;) |
| 몰래 입력 종료 및 저장 | `⌃⌥;` 다시 누르기 또는 `Esc` |
| 입력 중 지우기 | `Backspace` |
| 최근 메모 보기 | 메뉴바의 `shh` 클릭 |
| 메모 파일 위치 열기 | 메뉴바 `shh` → 메모 파일 열기 |

> 몰래 입력 중에는 메뉴바 글자가 `shh·`로 바뀌어요. 나만 알아챌 수 있는 작은 신호예요.
>
> 입력 중에는 이어 쓰기와 백스페이스만 돼요. 화면에 안 보이니 방향키로 커서를 옮겨도 위치를 알 수 없어서 일부러 막아뒀어요. 일단 막 적고, 정리는 나중에!

## 설치

아직 배포용 빌드는 없어서 Xcode로 직접 빌드해야 해요.

1. 레포를 클론해요.
   ```bash
   git clone https://github.com/qoxkal/shh.git
   ```
2. `shh.xcodeproj`를 Xcode로 열어요.
3. **Product → Archive** → **Distribute App** → **Custom** → **Copy App**으로 `shh.app`을 만들어요.
4. `shh.app`을 응용 프로그램 폴더로 옮기고 실행해요.

맥을 켤 때 자동으로 실행하려면 **시스템 설정 → 일반 → 로그인 항목**에 shh를 추가하세요.

### 요구 사항
- macOS 26.5 이상

## 메모는 어디에 저장되나요?

```
~/Library/Application Support/shh/memos.md
```

- 메모는 **내 맥에만** 저장돼요. 서버로 보내거나 동기화하지 않아요.
- 그냥 마크다운 파일이라 어떤 텍스트 편집기로도 열고 고칠 수 있어요.
- 형식은 이래요.
  ```markdown
  ## 2026-10-30 01:12
  메모 내용

  ## 2026-10-30 09:45
  다음 메모
  ```

## 어떻게 동작하나요?

키 입력을 가로채는 방식(키로거 방식)이 **아니에요.**

단축키를 누르면 완전히 투명한 입력창(`NSPanel`)이 키보드 포커스를 가져가요. 화면에는 아무것도 보이지 않지만 입력은 이 투명한 창으로 들어가고, 모드를 끌 때 그 내용을 파일에 저장해요.

- 손쉬운 사용, 입력 모니터링 같은 **특수 권한이 필요 없어요.**
- macOS 기본 입력기를 그대로 쓰기 때문에 **한글 조합이 자연스럽게** 돼요.
- 몰래 입력 모드가 꺼져 있을 때는 키 입력에 전혀 관여하지 않아요.
